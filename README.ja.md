# OCTGN版 FF TCG（日本語版）の導入手順

このガイドでは、OCTGNにFFTCGのゲームプラグインと日本語カード画像をインストールする方法を説明します。OCTGN本体がまだインストールされていない場合は、[OCTGN公式サイト](https://www.octgn.net/)から先にインストールしてください。

ゲームプラグインとカード画像パックは別々のファイルです。両方をインストールしてください。

## 1. ゲームプラグイン（`.nupkg`）をダウンロードする

最新の `.nupkg` ファイルを、次のいずれかからダウンロードしてください。

- [配布用Google Driveフォルダー](https://drive.google.com/drive/u/0/folders/1-iuTjSH1AWa7XC_9IeIV9d697vBoAuYd)
- [GitHub Releases](https://github.com/eureka-bots/fftcg-octgn-plugin/releases)

`.nupkg` ファイルは展開したり、拡張子を変更したりしないでください。

## 2. `.nupkg` をOCTGNにインストールする

1. OCTGNを終了します。
2. エクスプローラーのアドレス欄に `%USERPROFILE%\Documents\OCTGN\LocalFeed` と入力して開きます。フォルダーが存在しない場合は作成してください。
3. ダウンロードした `.nupkg` ファイルを `LocalFeed` フォルダーにコピーします。
4. OCTGNを起動し、**Games Manager** タブを開きます。一時的にフリーズすることがありますが、読み込みに時間がかかっているだけです。終わるまで待ちましょう。
5. 左上のフィード選択欄から **Local (Developers)** を選びます。
6. 一覧から **Final Fantasy TCG** を選び、**Install** をクリックします。

## 3. 日本語カード画像パックをインストールする

1. [配布用Google Driveフォルダー](https://drive.google.com/drive/u/0/folders/1-iuTjSH1AWa7XC_9IeIV9d697vBoAuYd)を開き、日本語（`ja`）用の `.o8c` ファイルをダウンロードします。英語（`en`）用ではなく、日本語用を選んでください。
2. OCTGNの **Games Manager** タブで **Add Image Packs** をクリックします。
3. ダウンロードした日本語の `.o8c` ファイルを選択し、インストールが完了するまで待ちます。

画像パックは展開せず、そのまま **Add Image Packs** から読み込んでください。

## ゲームの始め方と基本操作

ここではOCTGN上の基本操作を説明します。FFTCGのルールそのものを置き換えるものではありません。
ゲーム内のメニュー名は日本語表示に合わせています。OCTGN本体の **Games Manager** など、プラグイン外の画面は英語表記のままです。

1. OCTGNで **Final Fantasy TCG** の対戦ルームを作成または参加し、自分のデッキを読み込みます。
2. 対戦テーブルで各プレイヤーが **Tab**（または **ゲーム... > 次のフェイズへ**）を押し、デッキのフォーマットを選びます。両プレイヤーの準備ができると、先攻を決めるダイスロールが表示されます。
3. 先攻のプレイヤーはもう一度 **Tab** を押し、先攻かどうかを尋ねられたら **はい** を選びます。
4. **Deck > ドロー... > カードを5枚引く／マリガン**（または **F12**）で初手5枚を引きます。マリガンする場合は、もう一度実行して新しい5枚を引きます。
5. 両プレイヤーの初手が決まったら、先攻プレイヤーがもう一度 **Tab** を押して最初のターンを開始します。

### ターンの進め方と基本アクション

- ターンプレイヤーは **Tab** でフェイズを進めます。順番は **アクティブフェイズ**（自分のカードがアクティブになる）→ **ドローフェイズ** → **メインフェイズ1** → **アタックフェイズ** → **メインフェイズ2** → **エンドフェイズ** です。先攻プレイヤーの最初のドローフェイズでは1枚、その後のドローフェイズでは2枚が自動で引かれます。エンドフェイズの後にもう一度 **Tab** を押すと相手のターンになります。手札が6枚以上あるとターンを終了できません。
- カードを右クリックするとアクションメニューが開きます。手札のカードは **プレイ／キャスト** でプレイします。CPを得るには、手札のカードで **捨てる（CPを得る）**（そのカードの属性のCPを2点）を使うか、バックアップで **ダルにしてCPを得る**（使用できる属性のCPを1点）を使います。
- フォワード、バックアップ、モンスターの状態は **ダル／アクティブ** で管理します。バトル時はフォワードを右クリックし、**バトル... > アタック**、**パーティーアタック**、または **ブロック** を選ぶと攻撃・防御を表示できます。これらの操作は宣言の表示と通知を行うもので、カードを自動でダルしたり、バトルをすべて処理したりはしません。
- ダメージを受けたときは **Deck > ダメージを受ける** を使います。デッキの一番上のカードがダメージゾーンに移動し、そのカードがEXバーストを持つ場合は通知されます。効果はカードのテキストに従って処理してください。
- 一部のカード効果は自動処理または選択画面に対応していますが、すべてのカード効果が自動で解決されるわけではありません。カードのテキストを確認し、残りの効果は手動で処理してください。

### ホットキー

対戦のテンポを保つため、ホットキーの使用を強くおすすめします。まずは **Tab**、**F12**、**Ctrl+X**、攻撃時の **Alt+A／Alt+P／Alt+D** から覚えると便利です。カードやデッキに対するキーは、対象のカードまたはグループを操作する場面で使ってください。

| キー | 操作 |
|---|---|
| **Tab** | 次のフェイズへ |
| **F1**～**F6** | フェイズへ移動：F1 アクティブフェイズ、F2 ドローフェイズ、F3 メインフェイズ1、F4 アタックフェイズ、F5 メインフェイズ2、F6 エンドフェイズ |
| **F7** | 相手にターンを渡す |
| **Alt+X** | 6面ダイスを振る |
| **Ctrl+R** | リアクションを宣言 |
| **Alt+A**／**Alt+P**／**Alt+D** | アタック／パーティーアタック／ブロック |
| **Ctrl+X** | 捨てる（CPを得る）（手札のカードを捨てて、その属性のCPを2点得る） |
| **Ctrl+1**／**Ctrl+2** | 選択中のフォワードに与えられたダメージを+1000／-1000 |
| **Ctrl+Q**／**Ctrl+W** | 選択中のフォワードのパワーを+1000／-1000 |
| **Alt+Q** | アビリティを宣言 |
| **Alt+S** | ハイライトを解除 |
| **Alt+T** | 対象にする／解除 |
| **Alt+C** | テーブル上では「フォワードのパワーを計算」、カード上では「既定のカウンターを追加」 |
| **Ctrl+C** | 既定のカウンターを除去 |
| **Ctrl+S** | シャッフル |
| **Ctrl+D** | カードを1枚引く |
| **F12** | 初期手札を5枚引く／マリガン |

通常のターン進行には **Tab** を使ってください。**F1**～**F6** はフェイズを直接切り替えるため、その間のフェイズ処理を飛ばすことがあります。**F7** は現在のフェイズに関係なく相手へ操作を渡すので、通常はエンドフェイズ後に **Tab** を押してターンを渡してください。

## インストールできない場合

- **Local (Developers) にゲームが表示されない場合:** `.nupkg` が `Documents\OCTGN\LocalFeed` にあることを確認し、OCTGNを再起動してください。Windowsの設定で「ドキュメント」フォルダーが別の場所に移動されている場合は、その場所の `OCTGN\LocalFeed` にコピーしてください。
- **カード画像が表示されない場合:** 日本語（`ja`）の `.o8c` を選び、**Add Image Packs** から読み込んだことを確認してください。
